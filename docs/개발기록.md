# 림켓몬 (Rimketmon)

림월드 동물 + 림볼 가상현실 배틀 모드.

## 폴더 구조
```
Rimketmon/    ← 이 폴더가 "림월드 모드" 본체. 통째로 림월드 Mods 폴더에 복사
  About/About.xml, Preview.png
  Defs/                 림볼 아이템, 능력, 뇌 손상, 사운드 정의
  Sounds/Rimket/*.ogg   BGM/효과음 (저작권 있는 임시 음원, README.txt 참고)
  Textures/Things/RimketBall.png   림볼 아이콘 (임시 그림)
  1.6/Assemblies/Rimketmon.dll     컴파일된 코드
ModSource/    모드 C# 소스 + csproj + build.bat (DLL 다시 빌드할 때만 필요, Mods 폴더에 넣지 않아도 됨)
Engine/       순수 C# 전투 엔진 (림월드 불필요)
Tests/        엔진 테스트 (81개)
Tools/        기술 표 생성 스크립트
```

## 림월드에서 테스트하는 방법
1. **설치**: `Rimketmon` 폴더를 림월드 `Mods` 폴더에 복사 (Steam 기본: `C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods`).
2. **모드 활성화**: 게임 메인 메뉴 → 모드 → **Royalty(로열티 DLC)**, **림켓몬** 체크 → 재시작. (림켓몬은 Royalty 아래에 오도록 자동 정렬됩니다.)
3. 새 게임을 시작하고(또는 기존 세이브 로드) **개발자 모드** 켜기: 옵션 → 개발자 모드. 화면 위에 벌레 아이콘(디버그 액션)이 생깁니다.
4. 디버그 액션 → **림켓몬** 항목:
   - `정착민: 림볼 5개 + 초능력 레벨 +1` → 정착민을 클릭 (여러 번 클릭하면 레벨이 올라감)
   - `동물: 내 파티에 추가(복제)` → 야생 동물 클릭 (림켓몬 파티 만들기, 여러 마리 가능)
   - `동물: 6티어로 재굴림` 등 → 동물의 티어 확인/강제
   - `동물: 배틀 즉시 시작` → 야생 동물 클릭 (던지기 과정 생략)
   - `파티 비우기`
   - 림켓몬 메뉴의 개발자 탭 → **랭크 점수 / BP 디버그**: 점수·BP·연승·승·패·최고점수를 ←→(Shift ±10, Ctrl ±100)나 +/− 버튼으로 조절, 점수 초기화/랭크 기록 전체 초기화
5. **실제 흐름 테스트**: 림볼을 받은 정착민을 선택하면 하단에 **림볼 던지기** 능력 버튼이 생깁니다(최대 2초 뒤 부여). 클릭 → 야생 동물 지정.
6. 동물을 클릭하면 정보창에 `림켓몬: 속성 · 티어 · Lv` 한 줄이 보입니다.
7. 문제가 생기면 `F12`(로그창)에서 `[림켓몬]`과 빨간 오류를 확인하세요. 오류 메시지를 그대로 보내 주시면 바로 고칩니다.

**확인할 것**: 진입 연출이 나오는지 / BGM이 나오고 반복되는지 / 기술·교체·기본 공격·접속 해제 / 승리 후 포획·처치·놓아주기 / 림켓몬 없이 던질 때 경고창 / 패배 후 뇌 손상·사망 / 초능력 레벨 0 정착민은 버튼이 없는지.

dotnet build Tests

## 코드를 고쳤을 때 DLL 다시 빌드 (Windows)
`ModSource/build.bat`의 림월드 `Managed` 경로를 확인하고 실행 → `Rimketmon/1.6/Assemblies/Rimketmon.dll`이 갱신됩니다.
포함된 DLL은 Linux에서 실제 1.6.4871 `Assembly-CSharp.dll`을 참조해 컴파일한 것이라, 게임에서 로드가 안 되면 이 방법으로 직접 빌드하세요.

## 연출 / UI
- **진입 연출**: 던진 순간 현재 화면이 물결처럼 울렁이며 점점 어두워지고 → 두 번 번쩍 → 배틀 창. (설정에서 끌 수 있음)
- **BGM**: 배틀 중 반복 재생, 림월드 기본 음악은 잠시 꺼짐. 승리 후 선택 단계에서 승리 음악. 피해 효과음 3종(보통/굉장/별로). 설정에서 BGM 끄기·볼륨·효과음 끄기.
- **배틀 UI**: 포켓로그 320×180 화면을 좌표·시간 그대로 재현(아레나 배경, 정보 상자, 파이볼 트레이, 메시지/명령/기술 창, 트레이너 등장·볼 던지기). 정착민 단계는 초상화 표시.
- ⚠ `Rimketmon/Sounds/Rimket/*.ogg`는 팬게임에서 가져온 **저작권 있는 임시 음원**입니다. 공개 배포 전에 교체하세요(같은 파일명으로 덮어쓰기).

- **기술 연출**: PokeRogue `battle-anims` 데이터를 그대로 재생한다(924개 기술, 스프라이트 시트 382장, 효과음 1117개). 설정의 "기술 애니메이션"으로 끈다.
  데이터는 `Tools/PackAnims.py`가 만든 `Rimketmon/Anims/anims.gz`, 시트는 `Textures/Rimket/anim`, 소리는 `AnimSfx/*.ogg`. 재생기는 `ModSource/MoveAnim.cs`.
  가산(ADD) 합성·배경 이벤트·화면 흔들림은 아직 없다(밝기만 근사).
- **BGM**: 포켓로그 방식. 곡을 끝까지 재생한 뒤 루프 지점(battle_wild 12.703초 등)으로 돌아가 끊김 없이 반복한다. 야생=battle_wild, 관장전=지역 관장 곡 중 하나, 승리=victory_gym. 파일은 `Bgm/*.ogg`.
- **경험치**: 상대를 쓰러뜨리면 싸운 내 림켓몬이 나눠 받고 경험치 바가 찬다. 레벨은 배지 상한으로 고정이라 바는 다음 레벨 직전까지만 찬다.
- **교체**: 배틀 중 "림켓몬"을 누르면 포켓로그 파티 화면(party-ui-handler)이 그대로 열린다. 슬롯을 고르면 우하단에 "교체한다 / 능력치를 본다 / 그만둔다"가 뜨고, 쓰러진 림켓몬은 "싸울 수 있는 기력이 남아 있지 않습니다!"가 나온다. 지금 싸우는 림켓몬은 맨 앞 큰 슬롯.
- **요약 화면**: 포켓로그 summary-ui-handler 그대로(프로필/스테이터스/기술 3탭, ←→ 탭 이동, ↑↓ 앞뒤 림켓몬). 프로필=타입·특성·성격 문장, 스테이터스=성격 보정 색(올림 분홍/내림 파랑)·경험치 막대, 기술=위력/명중/분류 박스·설명 스크롤·Z로 기술 순서 교체. 왼쪽에 친밀도 하트. 개체값·도구·융합·이로치는 림켓몬에 없어 뺐다.
- **언어**: 모드 설정과 인게임 설정에 "언어(한국어/English)"가 있다. 즉시 바뀐다. 종족·기술·특성·성격 이름/설명과 PokeRogue 번역 전투 메시지는 PokeRogue 영어 번역, 직접 쓴 메뉴·전투 문구는 `Engine/Data/Lang.cs`의 조각 사전으로 치환한다. 사전에 없는 문구와 이미 저장된 림켓몬의 이름(포획 때 저장됨), 림월드 알림창 문구는 한국어로 남을 수 있다. 영어 데이터 재생성: `Tools/GenEnData.py`.
- **성격·친밀도**: 포켓로그와 같은 25종 성격(±10%)을 스폰 때 무작위로 정하고 저장한다. 친밀도(0~255, 기본 70)는 전투에서 이길 때마다 오른다. 이전 세이브는 노력(보정 없음)으로 불러온다.
- **관장**: 평행세계 트레이너라 이긴 관장도 다시 나온다. 이길 때마다 배지 +1. 사망/영구 제외 기능은 없다.
- **개발자 탭**: 림월드 개발자 모드일 때만 관리창에 나타난다. 관장 선택 도전, 종족/레벨 지정 야생 배틀, 배지 수 조절, 전체 회복.
- **스프라이트**: 야생/내 림켓몬은 림월드 동물의 실제 그래픽(`RimSprite`, 몸집에 따라 크기), 트레이너의 림켓몬은 팬게임 스프라이트, 플레이어는 림월드 폰 초상.
- **볼 던지기**: 포켓로그 summon 데이터 그대로(가로 650ms 선형, 세로 150ms 상승→500ms 하강+1440° 회전). 볼 그림은 아틀라스의 'pb' 프레임, 도착하면 열림 파티클.
- **배경**: `ArenaPicker`가 발밑 지형·실내/동굴·눈·주변 반경 10칸의 용암/물/얼음/모래/진흙/풀/나무/무덤과 바이옴으로 아레나를 고르고, 밤(19~5:30시)엔 푸른 어둠을 덮는다.
- **레벨**: 내 림켓몬은 항상 배지 상한(배지 N개 → (N+1)×10)으로 맞춰진다.
- **한글 문구**: 기술/특성 이름·설명은 PokeRogue `locales/ko`가 기준(`Tools/GenGameData.py --prko`). 전투 메시지 템플릿은 `Tools/GenMsgData.py` → `MsgData.cs`, 조사는 `Msgs.Josa`가 자동 처리("은(는)" 같은 표기도 정리).

## 규칙 요약 (v2)
- **종족**: 동물은 스폰 시 실제 포켓몬 종족(1096종)을 받는다. 최종 티어의 종족 풀에서 PokeRogue 바이옴 희귀도 가중치로 선택, 저장 후 고정. 티어 = 종족값 총합(<310/<390/<465/<520/<600/≥600). 6티어는 상향으로만(기본 티어별 0.02/0.05/0.15/0.5/2%), 해금 레벨 상한 31(660 이상은 51).
- **야생 레벨**: 배지 0개 1~10, 1개 11~20 … 최대 100. 야생/포획 개체는 진화하지 않음.
- **기술**: 습득기술(레벨 이하) 중 최근에 배운 것부터 4개. 공격기를 우선하고 변화기는 최대 절반까지 섞으며, 이 모드에서 못 쓰는 기술(`Move.Dud`)은 뽑지 않는다. 전체 833종이 엔진에 등록되어 있다(아래 "기술·특성 구현 현황"). 사용 가능한 기술이 없으면 발버둥(위력 50, 최대 HP 1/4 반동). 사람은 기본 공격 40~90.
- **특성**: 일반 특성 중 무작위. 317종 중 317종 전부를 엔진이 처리한다(`Engine/Battle/RimketBattle.Abil.cs`). 성별·더블 배틀은 구현되어 있다. 전투 밖 효과가 전제인 4종(볼줍기·꿀모으기·도주·커맨더)만 효과가 없다(`AbilityCatalog.Inert`). 도구 관련 특성(서투름·점착·긴장감·소매치기·매지션·수확·반추·볼주머니·먹보·익은열매·내려놓기·줍기·멀티타입·AR시스템)은 도구 시스템과 함께 동작한다.
- **정착민 스탯**: 정신감응력 × 초능력 레벨 × 100 ÷ 6 (각 120 상한). 림켓몬 전멸 후 정착민 HP 단계. 패배 = 사망(모드 설정 "패배 시 사망"으로 혼수+중증 손상으로 변경 가능).
- **관리 메뉴**(화면 우하단의 작은 림볼 아이콘, 우클릭 드래그로 위치 이동): 포켓로그 메뉴/파티/요약/설정 UI. 파티(순서/요약/꺼내기), 림켓몬 센터(팬게임 Pokémon Essentials의 센터·마트 맵을 그대로 이식. 림켓링크 정착민이 방향키/WASD로 걸어 다니며 간호사=무료 전회복 / PC=림켓몬 관리(파티) / 왼쪽 계단=마트의 점원=프렌들리숍(림볼·도구·열매·소비 4탭, 스크롤바/휠). BGM·효과음도 원작 그대로. Tools/PackCenter.py로 재생성), 체육관(전용 창, 슬롯머신 추첨으로 관장 결정), 랭크전(준비 중), 설정.
- **관장전**: 이세계 트레이너(PokeRogue 관장 데이터). 파티 레벨 = 현재 배지 단계 상한. 파티 전멸 후 관장 본인(스탯 합 600)이 직접 싸우며 패배 시 사망(설정). 승리 시 배지 +1 → 레벨 상한 +10.
- **설정**: 게임 속도, HP바 속도, 메시지 수동 넘김, 데미지 숫자, 기술 애니메이션, 상성 힌트, 기술 정보, 특성 표시, 상대 기술 표시, 전환 연출, BGM/효과음 볼륨, 파티 상한, 포획 확정 등.
- ⚠ 포켓몬 이름/데이터/음원은 닌텐도 IP입니다. 공개 배포 전에 데이터 교체·음원 교체를 검토하세요. 트레이너 스프라이트는 아직 미구현.

## 더블 배틀 (`Engine/Battle/RimketBattle.Double.cs`)
- 시작: `RimketBattle.DoubleTrainer(...)`, `RimketBattle.DoubleWild(...)`. 양쪽 2칸(`BattleSide.Slots`).

- 범위기(열풍·지진 등) 0.75배, 같은 편이 맞는 기술, 따라가기·분노가루·스포트라이트·피뢰침/마중물 끌어당기기, 도우미, 자리바꾸기, 헬핑핸드 등 같은 편 전제 기술 9종과 플러스/마이너스·배터리·파워스폿·프렌드가드·치유의마음·텔레파시·리시버·화학변화·코스타·위로의약·환대·공생·프로펠러테일·강건 특성이 동작한다.

## 개체값 (IV)
- 림켓몬마다 HP/공격/방어/특공/특방/스피드 개체값 0~31이 스폰 때 무작위로 정해져 저장된다. **6티어 종족은 전부 31(6V)**. 스탯 공식은 원작과 같다: `(2×종족값 + IV) × 레벨 / 100 + …`. 정착민·트레이너 본인(Neutral)은 개체값이 없다.
- 요약 > 프로필 페이지 아래에 개체값이 한 줄로 보인다(31은 분홍, 0은 파랑, 6V는 오른쪽에 "6V"). 개체값이 없던 예전 세이브는 불러올 때 한 번 굴려 저장한다.

- 바닥의 림볼은 정착민으로 우클릭 → 「소지품에 넣기」로 줍는다(`FloatMenu_RimketBall.cs`; 던지려면 소지품에 있어야 한다).

- 배틀 기술창: 속성색 줄 + 속성 아이콘 + 기술명 + PP를 한 칸에(포챔스 식).
- 상대 이름 배너(트레이너 인트로)에서 볼 던지는 소리 제거.
- 까마귀 등 프레임 설정이 없는 새도 메뉴 초원에서 날도록 판정 확장(게임에서 확인 못 함).

- 치료 효과음(pkmn_healing)의 앞쪽 0.6초 무음과 뒤 무음을 잘라 2.5초로 줄이고, 번쩍임·치료 완료 타이밍을 그 길이에 맞춤.
- 패러독스(및 모든) 배틀 종료 시 같은 프레임의 클릭/키가 아래 포켓몬 메뉴로 새어 메뉴가 꺼지던 버그 수정.
- 챔피언 배지를 누르면 티어 표시 토글(켜면 금색 테두리+ON, 끄면 회색+OFF): 현재 맵의 모든 동물 머리 위에 "N티어" 표시.
- 볼 대상: 일반 볼 = 야생·적대 세력·우리 동물. 우호/중립 세력 동물은 일반 볼 불가. 마스터볼은 모두 가능하나 우호 세력 동물은 호감도 감소.
- 세레나 튜토리얼에 "챔피언 배지는?" 질문 추가(만지면 특별한 일이 일어난다는 소문).
- 메뉴 초원의 사람 그림이 그림자보다 너무 위에 떠 있던 것을 아래로 내림. 까마귀: 비행 판정에 종족의 canFly 계열 값도 포함(게임 미확인).
- 용량 최적화(약 144MB → 약 80MB): 쓰이지 않는 연출 그림·효과음·종족 파일과 anims.gz의 도달 불가 연출 삭제, 트레이너 중복 프레임 파일 제거(Anims/trainer_frames.txt로 매핑), 모든 PNG 무손실 재압축(oxipng, 픽셀 동일).
- 항복/도망: 관장전·챔피언전·랭크전은 "항복한다", 패러독스는 "도망친다" 명령이 생김(패배 처리). 실수 방지를 위해 한 번 더 묻는 확인창(기본 선택 "계속 싸운다"). 정착민이 직접 싸우는 단계와 어둠의 트레이너 배틀에는 없음.
- 세레나 튜토리얼에 "?티어는 뭐야?" 질문 추가(완전 무작위, 원작에 없던 고점 가능).
- 랭크전 상대 전용 AI(`RankedAI`): 기대 피해 + 선공/한 방 판단. 랭크에서만 사용(패러독스·관장·야생은 기존 AI). 교체 판단 코드는 있으나 시험에서 약해져서 꺼 둠(NoSwitch). 같은 팀 150판: 랭크 AI 상대 72승 vs 기존 AI 상대 62승.
- 챔피언 배지 토글을 켜면 동물 머리 위에 "N티어 종족명" 표시 + 종족명 "(이름)" 표시가 개발자 모드 없이도 켜짐(요약창·패러독스 대상 목록).
- 랭크 AI 학습 환경(`Training/`): 헤드리스 환경(TrainEnv) + 관측 인코더(AiEncoder) + 학습·평가·내보내기 스크립트 + 신경망 추론(NeuralPolicy). 자세한 사용법은 Training/README.md. 아직 모드에는 연결 안 함.

### AI 학습: 상대 정보 가리기 (AiEncoder.HideFoeStats)
- 기본값 true. 화면에 안 보이는 상대의 공·방·특공·특방·속도를 관측에서 뺀다(HP·레벨·타입·상태·쓴 기술은 보임). 데미지 예상치도 상대 능력치 대신 내 파티 능력치 평균을 쓴다.
- 학습과 실제 사용에서 같은 값이어야 한다. 이전 학습(runs/ppo1)은 가리기 전 관측으로 돌린 것이라 새 관측과 호환되지 않는다 → 새로 학습해야 한다.
- 버그 수정: 발버둥을 쓴 직후 사슬묶기/앙코르/저주받은몸을 맞으면 "알 수 없는 기술 id: STRUGGLE"로 엔진이 죽던 문제(LastMoveId에 발버둥을 기록하지 않게 수정, 회귀 테스트 추가).
- 학습 안정화: TrainEnv가 엔진 예외를 잡아 그 판만 무효 처리(밤샘 학습이 멈추지 않음), 학습률이 끝으로 갈수록 서서히 감소.
- 엔진 예외 기록: 학습 중 엔진 예외는 `Training/TrainEnv/bin/Release/net8.0/engine_errors_PID.log`에 시드·양 팀·스택과 함께 남는다(같은 종류는 프로세스당 3번까지). 게임 디버깅에 쓴다.
- AI 2단계: 관측에 특성·지닌 도구 원-핫 추가(관측 3501차원, 랭크 풀에 나오는 특성 234·도구 120). 내 쪽은 항상, 상대는 특성이 발동 알림으로 드러난 뒤에만(도구는 가림). 랭크는 가방 아이템 사용 금지라 도구 사용 행동은 없음. 학습 팀은 두 팀이 같은 포맷에서 뽑힌다. 1단계 모델(1377차원)과 호환되지 않는다. 1단계 결과(500판): 랭크AI 52~54%, 기존AI 58%, 무작위 81%.

### 온라인 배틀 (방 코드, 싱글/더블)
- 메뉴 → "온라인 배틀". 한 명이 "방 만들기(싱글/더블)"로 6글자 코드를 받고, 다른 한 명이 "코드로 참가"에 입력한다. 스팀 친구가 아니어도 된다.
- 서버를 따로 두지 않는다. 림월드에 들어 있는 스팀 기능(Steamworks.NET)의 공개 로비 + 로비 채팅만 쓴다 → 관리할 서버 없음. 스팀판 림월드에서만 동작한다.
- 규칙은 랭크배틀과 같다: 내 파티(최대 6)에서 싱글 3마리·더블 4마리 선출, Lv50 고정, 종족·도구 중복 금지, 가방 아이템 없음. 점수·BP는 변하지 않는다.
- 방식: 두 컴퓨터가 같은 시드로 같은 전투를 돌리고 행동만 주고받는다(방장 = 엔진의 Player 쪽, 손님 = 화면을 뒤집어 Foe 쪽). 매 걸음 상태 해시를 비교해 어긋나면 그 판은 무효.
- 보호 장치: 모드 버전(DLL 지문)이 다르면 시작 안 함, 받은 림켓몬은 검사(?티어·미지 종족·능력 포인트 초과 거부), 턴 90초(+상대 응답 유예 20초), 선출 120초, 상대가 나가면 기권승, 동시 전멸은 무승부.
- 파일: `Engine/Online/OnlineProtocol.cs`(직렬화·검사·방 코드), `Engine/Online/OnlineSession.cs`(진행 약속), `ModSource/RimketOnline.cs`(스팀 로비), `ModSource/Window_RimketMenu.Online.cs`(메뉴), `ModSource/Window_RimketDouble.cs`(더블 간이 전투 화면).
- 더블 화면은 간이판이다: 칸마다 기술/교체/대상을 고르고 로그와 HP 바만 보여 준다(기술 연출 없음).
- 빌드: 프로젝트가 림월드 Managed 폴더의 `com.rlabrecque.steamworks.net.dll`을 추가로 참조한다.
- **확인 못 한 것**: 스팀 로비 연결 전체(방 만들기·코드 검색·입장·메시지 전달)와 두 화면은 실제 게임/스팀에서 한 번도 돌려 보지 못했다. 엔진·통신 약속만 자동 테스트(싱글/더블 각 120판 + 예외 상황)로 확인했다. 두 대의 PC(스팀 계정 2개)로 시험이 필요하다.

- 나무열매 가격: 원작의 싼 소모품 가격 대신 일반 도구 가격의 중앙값(현재 30 BP, 도구는 5~120 BP)으로 통일. 열매는 지닌 도구처럼 전투에서 먹어도 전투가 끝나면 돌아온다(원래 동작, 테스트 추가).

### AI 3단계: 자기학습
- 2단계(특성·도구 관측) 최종 500판: 랭크AI 54% / 기존AI 60% / 무작위 83% → 기준(60%) 미달, 모드 연결 보류.
- 자기학습 추가: 상대 시점 인코더(AiEncoder.AsFoe), TrainEnv 상대 모드 3(정책 파일의 신경망이 상대), 과거 정책 풀(50만 step마다 저장, 최근 10개), 랭크AI/기존AI 30% 혼합. 평가는 매번 다른 300판.
- 신경망 추론(NeuralPolicy)은 0이 아닌 입력만 곱하도록 최적화.
- 학습 속도 개선: 환경 N개를 C# 프로세스 하나가 스레드로 동시에 돌리고 파이썬과는 걸음마다 한 번만 주고받는다(`BatchVecEnv`, 기본값). 예전 방식은 `--subproc`. 2코어 샌드박스에서 학습 fps 약 350 → 1080. 이를 위해 엔진의 전투 간 공유 상태(화학변화가스·매직룸 조회기)를 전투별로 분리하고 능력치 함수 캐시에 잠금을 넣었다.
- 학습 속도 점검 결과: 자기학습 한 걸음에서 상대 신경망 추론이 C# 시간의 절반 이상이었다. 가중치를 입력 기준으로 뒤집어 0이 아닌 입력만 연속 메모리로 더하도록 바꿈(학습 환경 빌드는 SIMD 사용) → 추론 0.24ms → 0.07ms, 자기학습 환경 속도 약 1.6배. 관측은 공유 메모리로 전달. `train.py --profile N`으로 파이썬 쪽 시간 분석 가능.

### AI 4단계: 선출 학습
- 6마리 중 3마리 고르기를 학습 대상에 넣음(판 시작 3걸음, 행동 6칸 공용). 관측 7222칸(전투 3501 + 팀 프리뷰 3721). 자기학습 상대도 스스로 선출. 예전 모델은 `--widen`으로 이어받는다.
- 팀 구성(6마리 짜기) 학습은 방식 미정(통계 기반 가중치 vs 신경망 드래프트).

## 랭크 등급별 AI 강도 (확정 방향)
- 선출: 모든 등급이 좋은 선출을 쓴다(하위권도 공략을 보고 고른다는 설정). 등급에 따라 약화하지 않는다.
- 전투 중 판단: 하위권은 약하게(실수 섞기), 상위권은 강하게(학습 AI가 랭크AI를 확실히 이기면 적용). 구체 수치 미정.
- 팀 구성: 학습한 강한 조합은 점수가 높은 상대일수록 더 쓴다(전원 적용 아님).
- 현재 상태: 학습 AI는 모드에 미연결. 등급별 차이는 팀 풀(PU→Ubers)뿐이고 판단은 모든 등급이 같은 랭크AI.

### 사람 같은 랭크 상대
- **생각 시간**: 상대는 턴마다 보통 1~5초(평균 약 3.4초), 첫 턴·승부처(누군가 체력 35% 미만)는 조금 더, 약 8~9% 확률로 6~14초 더 고민한다. 양쪽이 동시에 고르는 것으로 쳐서, 내가 그보다 오래 고르면 기다림이 없다. 내가 먼저 고르면 "상대가 고르는 중…"이 뜬다. 선출도 평균 약 24초를 쓰며, 내가 먼저 끝내면 최대 15초까지 "상대가 선출하는 중…". 설정 "상대 생각 시간"으로 끌 수 있다(기본 켬). 랭크전만 해당(패러독스·관장·온라인 제외).
- **사람이 자주 하는 실수**(`HumanPlay`): 위력·상성만 보고 고르기(특성으로 무효인 기술, 명중 낮은 큰 기술, 물리/특수 착각) 40 / 잡을 수 있는데 욕심내서 능력 올리기 20 / 방금 쓴 기술 또 누르기 15 / 두 번째로 좋은 기술 고르기 25 (해당되는 것 중 가중 추첨).
- 실수 확률은 상대 점수로 정한다: 1000점 이하 30% → 1500점 이상 3%(직선). 선출은 등급과 무관하게 항상 좋은 선출.
- 시험(같은 300판, 단순한 플레이어 상대): 상대 승수 실수 없음 141 → 매 턴 실수 54.

### 팀 구성 학습 (통계 방식)
- 학습 중 모든 판에서 전투에 나간 양쪽 3마리씩의 승패를 `runs/<이름>/team_meta.txt`에 쌓는다(종족, 종족별 도구·특성·기술, 포맷별). 1분마다 저장, 다시 돌리면 이어서 쌓인다.
- 사용: 이 파일을 모드 폴더 `Rimketmon/Data/team_meta.txt`로 복사하면 랭크 상대 팀을 뽑을 때 승률이 높았던 것의 가중치가 오른다. 배율 = (승률/50%)^(4×반영정도), 판 수가 적으면 50% 쪽으로 보정(가상 100판).
- 반영 정도는 상대 점수로: 1100점 이하 0(지금과 동일) → 1500점 이상 1. 파일이 없으면 아무 변화 없음.

### 배틀 진행 템포 (원작 대전 영상 기준으로 재조정)
참고 영상(XY 통신 대전 2편)에서 잰 값: 문장 하나 약 1~1.2초 / 기술 이름 문장 → 연출 → HP 바 → 결과 문장(효과가 굉장했다·급소) / "쓰러졌다!" 문장 약 1초 → 쓰러지는 연출 약 1.5초 → 빈 자리 약 1초 → (턴 종료 효과) → "○○를 내보냈다!" 약 1초 → 볼·등장 약 1초 → 이름표.
- 기술: "○○의 △△!"를 다 찍고 약 0.4초 뒤에 연출 시작(전에는 문장과 동시에 시작).
- 피격/회복: HP 바가 다 움직인 뒤(+0.3초)에 다음 문장.
- 쓰러짐: 문장을 읽을 시간(약 0.65초) 뒤에 쓰러지는 연출, 그 뒤 약 0.8초 빈 자리. 전에는 문장·연출·다음 림켓몬 등장이 거의 붙어 있었다.
- 다음 림켓몬: 쓰러진 뒤 등장 문장 앞에 약 0.9초 뜸(교체는 0.6초). 랭크 상대는 여기에 "고르는 시간" 1~7초(보통 1.5~4초)가 더 붙는다. 등장 후 이름표가 뜨고 약 0.55초 뒤에 다음 문장(등장 특성 등).
- 행동과 행동 사이 약 0.4초. 모든 값은 배틀 속도 설정에 따라 줄어든다.

### 랭크 상대의 항복
- 가망 없음: 마지막 한 마리가 체력 35% 이하이고 내 쪽 전력이 한 마리분 이상 앞설 때 턴마다 55%, 전력 차가 아주 클 때 35%.
- 실수 뒤 민망: 실수한 턴에 자기 림켓몬이 쓰러졌으면 8%, 실수로 고른 공격이 전혀 안 통했으면 6%.
- 급소에 기분 상함: 급소로 쓰러졌으면 10%, 급소만 맞았으면 3%.
- 감정적인 항복(민망·급소)은 점수가 낮을수록 잦다(배율 1000점 이하 1.5 → 1500점 이상 0.5). 상대가 확실히 앞서 있을 때는 감정적으로 항복하지 않는다.
- 항복하면 한마디 → "항복했다!" → 내 승리. 점수·BP는 일반 승리와 같다.
- 시험(최하위권 설정 1500판): 가망 없음 112, 민망 71, 급소 26판(합계 14%).

### 체육관 규칙 변경
- 체육관·챔피언전은 림켓몬끼리의 승부: 내 파티가 전멸하면 정착민이 나서지 않고 그대로 패배. 져도 부상·사망 없음, 다시 도전 가능. 림켓몬이 한 마리 이상 있어야 도전할 수 있다.
- 관장 쪽은 그대로(파티가 쓰러지면 관장 본인이 나선다). 야생·어둠의 배틀의 정착민 직접 전투와 패배 위험도 그대로.
- 도전 확인창·체육관 화면·튜토리얼·설정 문구를 여기에 맞게 수정.

### 방문자의 림켓몬 승부 (새 이벤트)
- 정착지에 방문자 무리가 오면, 도착 약 1시간 뒤 무리당 40% 확률로 그중 한 명이 승부를 걸어온다. 미룰 수 없는 창("승부한다!" 하나)이 뜨고 바로 배틀.
- 림켓몬끼리만 싸운다(나도 상대도 본인은 나서지 않음). 상대는 3마리, 레벨은 내 레벨 상한에서 0~3 낮게. 항복 가능(패배 처리).
- 승리: 은 120~180 + 배지당 40개가 방문자 근처에 놓인다. 패배: "○○은(는) 눈앞이 깜깜해졌다!" → 검은 화면 → 림켓몬 센터에서 깨어나 간호사가 바로 치료(림켓링크가 없으면 센터 없이 회복만).
- 싸울 수 있는 림켓몬이 없으면 걸어오지 않는다. 개발자 모드에 "방문자의 림켓몬 승부 바로 시작" 추가.

- 체육관·챔피언전은 양쪽 모두 림켓몬만 싸운다. 관장의 림켓몬을 전부 쓰러뜨리면 승리. (관장 사망 처리도 더는 일어나지 않는다.)

### 기타
- 센터 회복 머신의 볼 위치: 표시등 중심(그림 좌표 x 93/99, y 28/32/36)에 정확히 맞춤. 이전 값은 가로 0.4칸, 세로 최대 0.6칸 어긋나 있었다.
- 어둠의 배틀 안내문에는 "트레이너를 없애면 배틀을 피할 수 있다"는 내용을 넣지 않는다(코드 주석으로만 남김).

### AI 학습: 왜 랭크AI 상대로 52%에서 멈추는가 (점검 결과)
- 선출 학습 30M step 결과: 랭크AI 52% / 기존AI 55% / 무작위 85%. 선출은 규칙 수준까지 배웠지만(무작위 상대 75% → 85%) 랭크AI 상대는 그대로.
- 점검 실험(규칙 선출, 랭크AI 상대 300판): 무작위로 두면 9%, 첫 번째 기술만 누르면 19%, **이번 턴의 난수와 상대 행동까지 미리 보고 가장 이득인 수를 고르는 반칙 에이전트도 34%**. 학습 모델은 52%.
- 원인: 랭크AI는 내 림켓몬의 정확한 능력치·특성·기술 전부를 보고 판단한다(피해 계산, 선출, 교체). 학습 모델은 화면에 보이는 것만 본다(상대 능력치·도구 숨김, 기술은 쓴 것만). 즉 정보가 불리한 쪽이 비긴 것이라 "60% 기준"이 애초에 불공평했다.
- 대응: `--full-info`(환경 변수 RIMKET_FULLINFO=1)로 상대 정보를 전부 보는 모델을 학습할 수 있게 함 → 랭크AI와 같은 조건. 관측 크기는 같아서 지금 모델에서 이어 학습할 수 있다. 평가에도 같은 옵션을 붙여야 한다. `eval.py --rule-pick`은 선출만 규칙에 맡겨 잰다.

### 지도 위의 림켓몬 (컴파일만 확인, 게임 안에서 미검증)
- **림켓몬 꺼내기**(능력, 림켓링크 착용자): 가리킨 자리(6칸 이내)에 볼을 던지면 파티 맨 앞 림켓몬이 실제 동물로 나와 착용자를 따라다닌다(FollowClose, 반경 2칸). 다시 쓰면 불러들인다. 나온 몸은 겉모습일 뿐이라 다치거나 죽어도 파티 데이터에는 영향 없음. 착용자가 죽거나 지도를 떠나면 자동으로 들어간다. 동물 몸이 없는 림켓몬(사람 등)은 꺼낼 수 없다.
- **방문자끼리의 승부**: 방문 중 약 40분마다 설정 확률(기본 5%)로 방문자 둘이 6칸 떨어져 마주 서서 림켓몬을 꺼내 싸운다. 실제 엔진(양쪽 동시 행동 경로)으로 진행하고, 로그를 한 줄씩 띄우며 등장·기절에 맞춰 동물을 꺼내고 넣는다. 기술 연출은 배틀 화면과 같은 재생기를 지도 좌표에 맞춰 그린다. 피해 숫자·불꽃 표시.
- 중단 조건(0.5초마다 검사): 트레이너나 림켓몬이 피해를 받음·쓰러짐·사망·정신 이상·불붙음·지도 이탈, 서로 적대, 정착지에 적대 위협 발생. 상대가 자리에 못 오면(30초) 취소. 저장 후 불러오면 진행 중이던 승부는 사라지고 꺼내 둔 몸은 치운다.
- 개발자 모드: "방문자끼리 림켓몬 배틀 시작(지도 위에서 구경)" — 방문자가 모자라면 정착민으로 채워 시험할 수 있다.

### 방문자 승부 조건·설정
- 림켓링크 착용자가 쓰러졌거나 자고 있거나, 안 나은 부상·치료 필요·병이 있거나, 정신 이상이면 방문자가 승부를 걸지 않는다.
- 모드 설정에 "이벤트"와 "랭크 상대의 성향" 묶음 추가: 방문자 승부 확률(기본 15%)·상대 마릿수·상금, 방문자끼리 승부 확률, 어둠의 배틀 켜기/끄기, 실수 빈도 배율, 항복 켜기/끄기, 감정적 항복 배율, 생각 시간 켜기/끄기와 길이 배율.

### 포켓몬의 몸 (지도 위 걷는 모습) — 컴파일만 확인, 게임 안에서 미검증
- 받은 자료(Pokémon Essentials용 Generation 9 Pack v3.3.8)에서 걷는 그림(Followers) 1,376장 중 모드에 있는 990종 전부의 것을 `Textures/Rimket/follow/<종족>.png`로 넣었다(약 4.7MB). 한 장 = 4방향(아래·왼쪽·오른쪽·위) × 4걸음. 키(m)는 같은 자료의 PBS에서 뽑아 `Data/pokemon_height.txt`에 넣었다(990종 전부).
- 구조: 투명한 동물 `RimketPokemonBody`(종족 하나)를 림월드가 움직이고, 모드가 매 프레임 그 위치에 종족별 걷는 그림을 그린다(방향 = 폰이 보는 방향, 움직일 때만 걸음 동작). 크기는 키에 따라 1.0~2.8칸.
- 적용: 림켓몬 꺼내기·방문자끼리 승부에서, 림월드 동물 몸이 있는 림켓몬은 그 동물로, 없는 림켓몬(포켓몬 종족)은 이 몸으로 나온다. ?티어처럼 그림이 없는 종족과 사람은 꺼낼 수 없다.
- 이 몸은 야생에 나오지 않고, 티어·포획·배틀·랭크 껍데기·어둠의 트레이너 후보에서 모두 제외했다. 꺼내 둔 몸에는 볼을 던질 수 없다.
- 개발자 모드 "포켓몬 모습으로 꺼내기 켜기/끄기": 동물 몸이 있어도 포켓몬 모습으로 꺼내 걷는 그림을 시험한다.
- 아직 안 쓴 자료: 폼별 걷는 그림(386장), 색이 다른 버전, 울음소리 1,167개.

### 지도 위 림켓몬 수정 (2차) — 컴파일만 확인
- 따라다니기를 **그림만 따라가는 방식**으로 바꿈: 실제 폰(길들인 동물)을 만들지 않는다. 틱을 쓰지 않고 화면을 그릴 때만 주인 등 뒤(약 1칸) 자리로 부드럽게 따라가며 그린다. 항상 "지금 파티 맨 앞" 림켓몬을 보여 준다. 동물 탭에도 나타나지 않는다.
  - 림월드 동물: 그 동물의 실제 그래픽을 4방향으로 그린다(걷는 동작 그림이 없어서 걸을 때 살짝 들썩임). 포켓몬: 걷는 그림 4방향 × 4걸음.
  - 꺼낼 때 울음소리: 림월드 동물은 그 동물의 소리, 포켓몬은 포켓몬 울음소리(방문자끼리 승부에서 나올 때도).
- 동물 색 문제의 원인: 같은 종이라도 개체마다 다른 그림(무늬)을 쓰는 동물이 있는데, 잡을 때 색만 적고 그림 경로는 적지 않았다. 그래서 "다른 그림용 색(흰색)"이 종 기본 그림(흑백)에 씌워져 하얗게 나왔다. 이제 색 2개 + 그림 경로를 함께 적고(Look = "색1|색2|경로"), 배틀·메뉴 그림과 따라다니는 그림 모두 그 개체의 그림을 쓴다. 예전에 잡은 개체(경로 없이 흰색만 적힌 것)는 종 기본 색으로 되돌린다.
  - 꺼낼 때마다 색이 바뀌던 것은 매번 새 동물을 만들어서였다. 이제 폰을 만들지 않고 개체에 적힌 그림을 쓰므로 바뀌지 않는다.
- 방문자끼리 승부: 거리 6칸 → 8칸(림켓몬 사이 4칸). 두리번거림 수정 — 대기 일에 바라볼 방향을 지정(overrideFacing)하고, 대기 일을 길게 줘서 방문자 무리의 원래 행동이 끼어들지 않게 함.
- 방문자의 림켓몬: 어노말리 실체를 빼고 림월드 동물만. 설정 "방문자가 포켓몬도 데려온다"(기본 꺼짐)를 켜면 자리마다 절반 확률로 포켓몬.

### 배틀·이벤트 다듬기 (3차) — 컴파일만 확인
- 방문자의 승부 신청을 포켓몬식 장면으로: 게임 정지 → 화면이 방문자에게 → 방문자가 남쪽(정면)을 봄 → 머리 위 느낌표(효과음) → 말풍선이 한 글자씩 → 클릭/Enter로 배틀. 림월드 기본 대화창은 쓰지 않는다.
- 승부를 걸지 않는 조건 추가: 지도에 적대적인 존재가 있음, 림켓링크 착용자가 소집 중.
- 울음소리: 배틀에서 림월드 동물이 나올 때 그 동물의 소리(soundCall)를 낸다. 쓰러질 때도 울음소리(동물·포켓몬 모두).
- 경험치가 오를 때 효과음(exp_gain), 내 림켓몬 체력이 20% 이하일 때 경고음(low_hp, 1.1초마다, 설정 "체력이 낮을 때 경고음"으로 끔). 소리는 참고 자료(포켓로그 audio/se)의 exp·low_hp·faint를 변환해 넣었다(경고음은 2.49초 묶음을 이어 붙임, 쓰러질 때 faint 효과음 추가).
- 내 쪽 림켓몬이 작으면(원숭이 등) 몸이 메시지 창에 가려지던 문제: 보이는 몸 높이가 64보다 작으면 최대 17만큼 위로 올려 발판 위에 온전히 보이게 함.
- BGM이 끊기는 문제(기술 연출 중): 효과음이 한꺼번에 많이 나면 소리 채널을 빼앗겨 BGM이 멈출 수 있다고 보고, BGM을 최우선 순위로·연출 효과음은 낮은 순위로 바꾸고, 그래도 끊기면 1초 안에 반복 지점부터 다시 트는 안전장치를 넣음. 원인은 추정이며 재현하지 못했다.
- 개발자 메뉴: "포켓몬 모습으로 꺼내기" 토글 삭제(방문자가 포켓몬을 데려오는지는 모드 설정 "방문자가 포켓몬도 데려온다"로 정한다). 정착민 지급 항목에 마스터볼 5개 추가.

## 2026-11-12 — 배틀 연출 보강(날씨·필드·상태·포획), 상대 AI 엿보기 수정, 방문자 승부 볼 던지기

- **상대 AI 엿보기 수정**: 싱글 전투에서 상대 AI가 플레이어의 교체가 끝난 뒤에 행동을 골라, 새로 나온 림켓몬에 맞춰 대응하던 문제를 고쳤다. 이제 턴 시작 시점(플레이어 행동 처리 전)에 기술·교체를 정한다(`preFoe`/`preSwitch`). 학습 기준 상대(랭크AI)도 함께 바뀌므로 이전 평가 수치와 직접 비교할 수 없다.
- **날씨·필드 사건**: `FieldChange` 사건의 `Value` = 날씨 | 필드<<4 | (턴 끝 이어짐이면 256). 화면은 엔진의 최종 상태가 아니라 이 사건으로 '지금 보여 줄 날씨/필드'를 따라간다(배지도 동일).
- **공용 연출**: 포켓로그의 common-* 연출 50개를 `Anims/anims.gz`에 `common…` 키로 추가(그림·소리 포함). 날씨 시작/턴 끝(30프레임 이하만 되풀이), 필드 시작, 상태이상(독·맹독·화상·마비·잠듦·얼음·혼란·헤롱헤롱), 씨뿌리기·저주·소금절임·조이기에 사용. 연출을 끄면 기존 색 번쩍임으로 대신한다.
- **지속 효과**: 날씨는 비 줄기/눈·싸라기눈/모래바람/햇살/난기류를 계속 그리고, 필드는 바닥 쪽을 필드 색으로 물들인다(일렉트릭필드는 스파크).
- **포획 연출**: 엔진이 "몬스터볼을 던졌다!"를 먼저 기록 → 화면에서 볼 던지기 → 열림 → 떨어져 튐 → 흔들림(성공 3번, 실패 0~2번) → 잠김(별)/튀어나옴. 효과음 pb_throw, pb_rel, pb_catch, pb_bounce_1/2, pb_move, pb_lock.
- **시체 제외**: `ChallengeBuilder.IsCorpseLike`(시체 def, 이름·라벨에 시체/사체/corpse)를 랭크 목록과 트레이너·방문자 파티 생성 모두에 적용.
- **방문자끼리 승부**: 림켓몬을 낼 때 트레이너가 볼을 실제로 던지고(`Projectile_RimketBall.ThrowThen`), 떨어진 자리에서 열리며 나온다. 볼이 열릴 때 전투 화면과 같은 빛 알갱이를 지도 위에 그린다(`RimketWorldComponent.AddBurst`, 플레이어의 꺼내기에도 적용).
- 미확인: 위 연출은 모두 게임 안에서 확인하지 못했다. 더블 배틀 화면에는 날씨·필드 연출이 아직 없다.
