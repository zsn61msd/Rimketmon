# 포켓로그 데이터 지도 (리버스엔지니어링 결과)

대상: `PokeRogue-Windows.zip` (Electron 패키지, 게임 폴더 = `resources/game/`).
결론부터: **암호화된 것은 없다.** 소스맵(`assets/*.js.map`)에 TypeScript 원본이 그대로 들어 있고, 이미지/오디오/애니메이션/번역은 평문 파일이다.
영상으로 UI를 재는 것보다 아래 "UI 좌표·타이밍" 항목(소스)을 읽는 쪽이 정확하고 빠르다.

작업용 경로(세션 스크래치): `pr2/full.zip`(원본 통짜), `pr_zip/ts/src`(소스맵에서 복원한 TS), `pr2/more/`(추출한 locales/battle-anims/fonts/se).
부분 추출: `unzip -qo full.zip "resources/game/<경로>/*" -d <출력>`

## 3. 기술 애니메이션 JSON 구조 (H)
```
{ "id":33, "graphic":"PRAS- Strike",            // images/battle_anims/<graphic>.png(+json)
  "frames":[[ {x,y,zoomX,zoomY,visible,target,graphicFrame,opacity,locked,priority,focus}, ...], ...],
  "frameTimedEvents":{ "0":[{frameIndex,resourceName,volume,pitch,eventType:"AnimTimedSoundEvent"}], ... },
  "position":.., "hue":.. }
```
- `target`: 0=사용자, 1=대상, 2=그래픽 셀 / `focus`: 어느 쪽 좌표계에 붙일지.
- 프레임 길이는 `getFrameMs`(약 1/60초 단위)로 재생. 이벤트 종류: 효과음, 화면 흔들림/배경(`AnimTimedBgEvent`), 스프라이트 효과(`AnimTimedUpdateBgEvent`).
- 구현 방침: 유니티에서 셀 리스트를 그대로 읽어 그리는 작은 재생기(`MoveAnimPlayer`)를 만들면 923개 연출이 데이터만으로 재생된다.

## 4. 번역(B) 사용법
- `locales/ko/move.json` : `{ "pound": {"name":"막치기","effect":"…"} }` → 기술 ID(camelCase)로 조회.
- `locales/ko/ability.json` : `{ "stench": {"name":"악취","description":"…"} }`.
- `locales/ko/battle.json`, `move-trigger.json`, `ability-trigger.json`, `battler-tags.json`, `status-effect.json`, `weather.json`, `terrain.json` : 전투 중 모든 메시지 템플릿(`{{pokemonName}}[[가]]` 형식 → 조사 규칙 필요).
- `menu-ui-handler.json`, `settings.json`, `command-ui-handler.json`, `party-ui-handler.json`, `pokemon-summary.json` : UI 문구.
- 한국어 문구가 이미 완성돼 있으므로 우리 기술/특성 한글 표기는 이 파일을 기준으로 맞추면 된다.

## 5. 이 모드에서의 활용 순서 (제안)
1. 번역 JSON으로 기술/특성/메시지 한글 통일 (가장 싸고 효과 큼).
2. `battle-anims` 재생기 → 기술 연출 일괄 적용.
3. `ability.ts`/`move.ts`의 attr 클래스를 엔진 효과 코드로 변환해 #24/#25 마무리.
4. UI는 소스 좌표를 그대로 사용(영상 분석 불필요).
